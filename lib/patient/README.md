# Patient App Module

This directory is reserved for the synchronized **Patient App** interface of **AAYUSATHI**.

## Target Responsibilities
- Patient authentication & profile management
- Appointment booking & booth scheduling
- Access to digitized medical records and sensor vital history
- Real-time notifications and consultation status

## Planned Architecture
```
patient/
├── screens/       # Mobile screens for patient workflows
├── widgets/       # Patient-specific reusable UI widgets
├── models/        # Patient-specific state or view models
└── services/      # Patient-specific communication & caching
```
