# Doctor App Module

This directory is reserved for the synchronized **Doctor App** interface of **AAYUSATHI**.

## Target Responsibilities
- Physician dashboard & active queue management
- Real-time patient telemetry & sensor readings review
- Teleconsultation & video booth communication
- Digital prescription and clinical consultation notes generation

## Planned Architecture
```
doctor/
├── screens/       # Doctor workflow and consultation screens
├── widgets/       # Doctor-specific clinical widgets & charts
├── models/        # Clinical queue and consultation models
└── services/      # Doctor-specific synchronization services
```
